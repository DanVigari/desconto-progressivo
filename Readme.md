# ⚡ Calcúlo de desconto progressivo

Um programa simples e eficiente desenvolvido para calcular o desconto progressivo de 5%, 10% e 15% com base no valor total da compra.

---

## 📌 Sobre o Projeto

O programa solicita o valor da compra e aplica automaticamente um percentual de desconto de acordo com faixas de valor pré-definidas, exibindo o valor do desconto e o valor total a pagar.

---

## 🖥️ Exemplo de uso

```
Digite o valor da compra: 250
Desconto de 10% aplicado. Valor do desconto: R$25.00. Valor total da compra: R$225.00
```
